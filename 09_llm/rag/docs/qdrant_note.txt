Qdrant 실습 메모

Qdrant 는 벡터 검색 엔진이다. 문서 임베딩을 컬렉션에 저장해두고
질의 벡터와 가까운 문서를 빠르게 찾아준다.

컬렉션을 만들 때 벡터 차원(size)과 거리 함수(distance)를 정해야 한다.
bge-m3 임베딩은 1024 차원이고, 정규화된 벡터라면 거리 함수는 COSINE 이 적절하다.
차원이 모델과 다르면 저장 단계에서 오류가 난다.

실행 모드는 세 가지다.
local 모드는 별도 서버 없이 지정한 디렉터리에 직접 저장한다.
파일 락을 쓰므로 한 번에 한 프로세스만 붙을 수 있고, 다 쓰면 close 해야 한다.
memory 모드는 프로세스 메모리에만 저장해서 종료하면 사라진다. 테스트용이다.
server 모드는 localhost:6333 의 Qdrant 서버에 붙는다. 여러 프로세스가 동시에 쓸 수 있다.

포인트는 id, vector, payload 세 부분으로 이루어진다.
payload 에 원문과 메타데이터를 넣어두면 검색 결과에서 바로 꺼내 쓸 수 있고
카테고리 같은 필드로 필터 검색도 할 수 있다.
포인트 id 는 부호 없는 정수나 UUID 만 허용된다.
