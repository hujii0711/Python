# 파이썬 기초 정리

## 리스트 다루기

리스트를 뒤집는 방법은 세 가지가 있다.
`reverse()` 는 원본을 제자리에서 뒤집고 None 을 반환한다.
`reversed()` 는 이터레이터를 돌려주므로 `list()` 로 감싸야 한다.
슬라이싱 `items[::-1]` 은 새 리스트를 만든다.

원본을 보존해야 하면 슬라이싱이나 `reversed()` 를 쓰고,
메모리를 아껴야 하면 `reverse()` 를 쓴다.

## 딕셔너리 다루기

키가 없을 때 기본값을 받으려면 `dict.get(key, default)` 를 쓴다.
없는 키를 자동으로 채우려면 `collections.defaultdict` 가 편하다.
두 딕셔너리를 합칠 때는 `{**a, **b}` 또는 `a | b` (3.9 이상) 를 쓴다.

## 컴프리헨션

리스트 컴프리헨션은 `[f(x) for x in xs if cond(x)]` 형태다.
제너레이터 표현식 `(f(x) for x in xs)` 는 결과를 한꺼번에 만들지 않아서
큰 데이터를 다룰 때 메모리를 적게 쓴다.

## 예외 처리

`try / except / else / finally` 순서로 쓴다.
`except Exception as e` 로 잡되, 잡을 예외를 좁게 지정하는 편이 좋다.
`finally` 블록은 예외가 나든 안 나든 항상 실행되므로 자원 해제에 쓴다.
파일이나 락처럼 닫아야 하는 자원은 `with` 문을 쓰는 것이 더 간결하다.
