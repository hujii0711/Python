# 파이썬 리스트 다루기

## 리스트 뒤집기

리스트를 뒤집는 방법은 세 가지다.
`reverse()` 는 원본을 제자리에서 뒤집고 None 을 반환한다.
`reversed()` 는 이터레이터를 돌려주므로 `list()` 로 감싸야 한다.
슬라이싱 `items[::-1]` 은 새 리스트를 만든다.

원본을 보존해야 하면 슬라이싱이나 `reversed()` 를 쓴다.
메모리를 아껴야 하면 `reverse()` 를 쓴다.
큰 리스트를 순회만 할 거라면 `reversed()` 가 새 리스트를 만들지 않아 가장 가볍다.

## 리스트 정렬

`sort()` 는 원본을 바꾸고 `sorted()` 는 새 리스트를 돌려준다.
`key` 인자에 함수를 주면 기준을 바꿀 수 있고 `reverse=True` 로 내림차순이 된다.
여러 기준으로 정렬하려면 `key=lambda x: (x.age, x.name)` 처럼 튜플을 돌려주면 된다.
파이썬 정렬은 안정 정렬이라 같은 키끼리는 원래 순서가 유지된다.

## 리스트 컴프리헨션

리스트 컴프리헨션은 `[f(x) for x in xs if cond(x)]` 형태다.
제너레이터 표현식 `(f(x) for x in xs)` 는 결과를 한꺼번에 만들지 않아서
큰 데이터를 다룰 때 메모리를 적게 쓴다.
중첩 반복은 `[y for x in xs for y in x]` 처럼 바깥 루프를 먼저 쓴다.

## 리스트 복사

`copy()` 나 `list(items)` 는 얕은 복사라서 안쪽 객체는 원본과 공유된다.
중첩 리스트를 완전히 떼어내려면 `copy.deepcopy()` 를 써야 한다.
`b = a` 는 복사가 아니라 같은 객체를 가리키는 이름을 하나 더 만드는 것뿐이다.
