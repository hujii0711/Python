# 판다스 결측치 처리 방법

## 결측치 확인

`df.isna().sum()` 으로 열별 결측치 개수를 센다.
비율이 궁금하면 `df.isna().mean()` 이 더 읽기 편하다.
`df.info()` 는 열별 non-null 개수와 자료형을 함께 보여준다.

## 결측치 채우기

`df.fillna(0)` 은 고정값으로 채우고 `df.fillna(df.mean())` 은 평균으로 채운다.
시계열 데이터면 `df.ffill()` 로 직전 값을 끌어오는 방식이 자연스러운 편이다.
범주형 열은 평균이 의미가 없으므로 최빈값이나 별도 범주로 채운다.

채우기 전에 결측이 왜 생겼는지 먼저 보는 것이 중요하다.
측정 실패로 빈 값과 애초에 해당 없음인 빈 값은 다르게 처리해야 한다.

## 결측 행 버리기

결측 행을 버릴 때는 `df.dropna(subset=["price"])` 처럼 대상 열을 좁힌다.
`df.dropna()` 를 그냥 부르면 한 열만 비어도 행 전체가 사라져서 데이터가 크게 준다.
`thresh` 인자로 최소 non-null 개수를 지정할 수도 있다.
