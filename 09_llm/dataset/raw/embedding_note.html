임베딩 모델 선택

어떤 모델을 쓸까

한국어와 영어를 함께 다뤄야 하면 BAAI/bge-m3 가 무난하다. 1024 차원 dense 벡터를 만들고 최대 8192 토큰까지 넣을 수 있다. 여러 언어를 한 벡터 공간에 넣기 때문에 한국어 질문으로 영어 문서를 찾을 수 있다.

속도가 더 중요하면 차원이 작은 모델을 쓴다. 차원이 작으면 저장 공간과 검색 시간이 함께 줄어든다. 대신 미묘한 의미 차이를 덜 구분한다.

정규화와 거리 함수

임베딩을 정규화하면 내적이 그대로 코사인 유사도가 된다. 정규화하지 않은 벡터에 코사인 거리를 쓰면 길이 차이 때문에 순위가 흔들린다. 저장할 때와 질의할 때 같은 방식으로 정규화해야 한다.

파인튜닝이 필요한 경우

도메인 용어가 많아 일반 모델이 헷갈리면 파인튜닝을 고려한다. 질문과 정답 문단 쌍을 모으고 하드 네거티브를 섞어서 학습시킨다. 데이터가 수백 건뿐이면 파인튜닝보다 청킹과 질의 보정을 먼저 손보는 편이 낫다.
